# Makefile Documentation for mqttaudio

This Makefile manages the installation, configuration, and service lifecycle of the `mqttaudio` project.

## Variables

| Variable | Default Value | Description |
|----------|---------------|-------------|
| `PRJ` | `mqttaudio` | The project name. |
| `DESTDIR` | `/usr/local/lib/${PRJ}` | Target installation directory. |
| `SRCDIR` | `$(HOME)/Projects/iot/${PRJ}` | Source directory of the project. |
| `LAUNCH` | `${PRJ}.sh` | Name of the launch script in the destination. |
| `SERVICE` | `$(PRJ).service` | Name of the systemd service file. |
| `PYENV` | `${DESTDIR}/.venv` | Path to the Python virtual environment. |
| `NODE` | `$(shell hostname)` | Hostname of the machine, used for node-specific configs. |
| `PYVER` | `3.11.2` | Python version to use for the virtual environment. |
| `PYFILES` | `*.py` | List of all Python files in the source directory. |

## Targets

### Installation & Updates

- **`all`** (Default): Aliased to `install`.
- **`install`**: Performs a full installation. Creates `${DESTDIR}`, sets up `${PYENV}`, and runs `update`.
- **`update`**: Updates Python files, configuration files (`${NODE}.toml`), the Makefile, and the service file in `${DESTDIR}`. Also prepares the launch script and deepseek prompt.
- **`pyfiles`**: Copies all Python source files to `${DESTDIR}`.
- **`${PYENV}`**: Creates a Python virtual environment using `uv` and installs dependencies from `requirements.txt`.

### Service Management

- **`start`**: Reloads the systemd user daemon, enables, and restarts the `${SERVICE}`.
- **`stop`**: Stops and disables the `${SERVICE}`.

### Maintenance & Cleanup

- **`lint`**: Runs `flake8` on the project source code with specific formatting rules.
- **`clean`**: Stops the service, removes the systemd unit file from `/etc/xdg/systemd/user`, and deletes `${DESTDIR}`.
- **`distclean`**: Runs `clean` and also removes the virtual environment `${PYENV}`.

## Installation Flow

1.  **Directory Setup**: `${DESTDIR}` and its subdirectories (`chimes`, `sirens`, `prompts`) are created with appropriate permissions.
2.  **Virtual Environment**: A virtual environment is created in `${PYENV}` using `uv`.
3.  **File Deployment**: Python files and configuration files (including node-specific `.toml`) are copied to `${DESTDIR}`.
4.  **Service Setup**: The `${SERVICE}` file is copied to the user's systemd directory.
5.  **Launch Script**: A launch script is generated by substituting the `PYENV` placeholder in `launch.sh`.

## Requirements

- `uv`: Used for virtual environment and package management.
- `systemd`: Used for service management.
- `flake8`: Used for linting.
- `sudo` access: Required for creating and managing `${DESTDIR}` and `${PYENV}`.
