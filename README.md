# mqttaudio

MQTT-controlled audio playback and speech interaction system.

## Documentation

- [Makefile Documentation](MAKEFILE.md): Details on installation, configuration, and service management using `make`.

## Getting Started

To install the project:

```bash
make install
```

To start the service:

```bash
make start
```

For more details, see [MAKEFILE.md](MAKEFILE.md).
